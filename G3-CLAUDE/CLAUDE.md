# Instrucciones para Claude Code

Proyecto de arquitectura G3 (UEM): viviendas temporales para 40 jóvenes en Ribera de Curtidores 31, Madrid. Autor: Adam.

- Lee primero `README.md` y el documento de inicio que indica.
- Los archivos `*.parteNNNdeMMM` son trozos: ejecuta `python3 _GITHUB/unir_trozos.py` antes de abrir esos modelos.
- Los `*.FICHA.md` describen modelos que no están en GitHub (demasiado pesados). No inventes su contenido: usa la ficha y los archivos que cita.
- Los `.3dm` se pueden leer con la librería Python `rhino3dm` (`pip install rhino3dm`).
- Las rutas absolutas `/Volumes/T7/...` dentro de documentos y scripts son del disco del autor; tradúcelas con `_GITHUB/MAPA_RUTAS.tsv`.
- Todo lo que se proponga debe cumplir el Código Técnico de la Edificación y justificarse con criterio técnico.
- Paneles y documentos: fondo blanco, sin títulos tipo etiqueta ni eslóganes; planos técnicos en blanco y negro.
